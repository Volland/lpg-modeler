## Purpose

Applies a script the tool generated — a full schema or a migration — to a running database, so the step from a reviewed script to a deployed schema is a single command that stops at the first failure and says exactly what ran.

## ADDED Requirements

### Requirement: Applying a script to a running Memgraph

`lpg apply <script> --target memgraph --uri <bolt-uri>` SHALL run each statement of a memgraph script against the instance, in file order, and print each statement as it succeeds. It SHALL stop at the first failing statement. It SHALL then report that statement's position, its text and the engine's message, report how many statements had already been applied, and exit non-zero. Credentials SHALL be taken from `--user` and from the `MEMGRAPH_PASSWORD` environment variable, never from a flag holding the password.

#### Scenario: Applying a generated schema to a fresh instance

- **WHEN** the memgraph script generated for a model is applied to an empty instance
- **THEN** every statement runs, the command exits zero, and the instance holds the constraints, indexes and enums the script declares

#### Scenario: A statement fails part-way

- **WHEN** a script's third statement creates a uniqueness constraint that existing data violates
- **THEN** the first two statements have been applied, the third is reported with the engine's message, no later statement runs, and the command exits non-zero

#### Scenario: Dry run

- **WHEN** `lpg apply` is run with `--dry-run`
- **THEN** the statements are printed in the order they would run and nothing is sent to the instance

### Requirement: Apply refuses scripts it should not run

`lpg apply` SHALL refuse, before connecting, a script whose header names a target other than the one requested, and a file that is not a script generated by this tool. It SHALL also refuse a script that contains statements marked destructive, unless `--allow-destructive` is given.

#### Scenario: Script for another target

- **WHEN** a neo4j migration script is applied with `--target memgraph`
- **THEN** an `apply-target-mismatch` error is reported and no connection is made

#### Scenario: Destructive migration without the flag

- **WHEN** a memgraph migration containing a statement marked destructive is applied without `--allow-destructive`
- **THEN** a `destructive-change` error names the marked element and nothing is run

#### Scenario: Target that cannot be applied

- **WHEN** `lpg apply` is run with `--target ladybug`
- **THEN** an `apply-unsupported` error names memgraph as the target apply supports
